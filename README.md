# InterviewBuddy AI

InterviewBuddy AI is a local interview-practice app for students and job seekers. It helps you work through realistic questions, receive constructive feedback, and identify areas to practice next.

## Problem statement

Interview practice can be difficult to structure, and it is not always obvious how to improve an answer. Candidates benefit from a low-pressure way to practice relevant questions and get clear, specific feedback.

## Solution

Choose a role and interview style, answer five questions, and get Gemini-generated feedback on each answer. At the end, review a separate, transparent checklist score and suggested practice topics.

## Implemented features

- Interview sessions for software engineering, data analysis, product management, and customer support.
- Mixed, behavioral, and technical interview styles, with friendly, standard, and challenging difficulty options.
- Five questions per session, selected from the local question bank.
- Answer validation and a character counter.
- Gemini feedback for each submitted answer: strengths, improvements, and a sample improved answer.
- Retry an answer or restart the question set.
- A final report with a deterministic local checklist score, feedback themes, and suggested topics.
- A Flask backend that reads `GEMINI_API_KEY` from the project-root `.env` file and sends requests to the Gemini API. The API key is not included in browser code.

The report score is calculated locally using answer length, text signals, and measurable details. It is not generated by Gemini and is not a hiring assessment. Answers are sent to the backend and Gemini to generate feedback; this project does not implement persistent answer storage or accounts.

## Tech stack

- **HTML** for the page structure
- **CSS** for the responsive visual design
- **JavaScript** for the interview flow, local question bank, and API requests
- **Python and Flask** for the feedback endpoint
- **Google Gemini API** for interview-practice feedback
- **python-dotenv** for loading the server-side API key from `.env`

## Setup and run

### 1. Install Python dependencies

Open a terminal in the project root (the folder containing `index.html`). On Windows, create and activate a virtual environment, then install the requirements:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If the project already has `.venv`, activate it and install or update dependencies with the last command.

### 2. Configure the Gemini API key

Create a file named `.env` in the project root, next to `index.html`, and add your own key:

```text
GEMINI_API_KEY=your_api_key_here
```

Replace the placeholder with your key. Do not commit or share `.env`, and never put the key in frontend JavaScript. The `.gitignore` excludes `.env`.

### 3. Start the Flask backend

In a terminal opened at the project root, run:

```powershell
.\.venv\Scripts\python.exe js\app.py
```

The backend listens at `http://127.0.0.1:5000`.

### 4. Serve the frontend locally

In a second terminal, also at the project root, start a local web server:

```powershell
python -m http.server 8000
```

Open <http://127.0.0.1:8000> in your browser. You can also use the VS Code Live Server extension. Use a `localhost` or `127.0.0.1` address; the Flask backend allows these local frontend origins.

### 5. Try a practice session

Choose **Start practicing**, set up your interview, and submit an answer of at least 20 characters. Gemini feedback appears after the backend responds. Continue through all five questions to see the final report.

## Troubleshooting

- **The backend says the API key is missing:** confirm `.env` is in the project root, the variable is named `GEMINI_API_KEY`, and restart Flask after changing `.env`.
- **The browser cannot reach the backend:** make sure Flask is running at `http://127.0.0.1:5000` and the frontend is served from `localhost` or `127.0.0.1`.
- **Gemini returns an error:** check the Flask terminal for the safe diagnostic status and confirm that the configured model is available to your Gemini API project.
