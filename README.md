# InterviewBuddy AI

InterviewBuddy AI is a local interview-practice app for students and job seekers. It helps you work through realistic questions, receive constructive feedback, and identify areas to practice next.

## Problem statement

Interview practice can be difficult to structure, and it is not always obvious how to improve an answer. Candidates benefit from a low-pressure way to practice relevant questions and get clear, specific feedback.

## Solution

Choose a role and interview style, answer five Gemini-generated questions, and get an AI evaluation for each answer. The session begins with a warm-up, gradually raises the challenge, and offers an optional personalized follow-up after each answer.

## Implemented features

- Interview sessions for Software Developer, Web Developer, Data Analyst, AI/ML Engineer, Electronics Engineer, Embedded Systems Engineer, Communication Engineer, and HR/Behavioral Interview roles.
- Mixed, behavioral, and technical interview styles, with friendly, standard, and challenging difficulty options.
- Five role- and experience-specific questions generated by Gemini for each session. A failed API request is shown as an error; local sample questions are not substituted.
- Answer validation and a character counter.
- Gemini answer evaluations with a score out of 100, strengths, specific weaknesses, missing concepts, clarity and relevance feedback, grammar suggestions, an improved example answer, and a contextual follow-up question.
- Optional follow-up practice based on the answer, with the previous question and answer sent as context for evaluation.
- Retry an answer or restart the question set.
- A final report with the average AI evaluation score, score range, recurring strengths and improvement areas, and topics practiced.
- A Flask backend that reads `GEMINI_API_KEY` from the project-root `.env` file and sends requests to the Gemini API. The API key is not included in browser code.

Answers and the immediately preceding question/answer context are sent to Gemini through the backend. This project does not implement persistent answer storage or accounts. AI scores are practice guidance, not hiring assessments, and may be imperfect.

## Tech stack

- **HTML** for the page structure
- **CSS** for the responsive visual design
- **JavaScript** for the interview flow and API requests
- **Python and Flask** for the feedback endpoint
- **Google Gemini API** for interview-practice feedback
- **python-dotenv** for loading the server-side API key from `.env`

## Setup and run

### 1. Install Python dependencies

Open a terminal in the project root (the folder containing `index.html`). On Windows, create and activate a virtual environment, then install the requirements:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If the project already has `.venv`, activate it and install or update dependencies with the last command.

### 2. Configure the Gemini API key

Create a file named `.env` in the project root, next to `index.html`, and add your own key:

```text
GEMINI_API_KEY=your_api_key_here
```

Replace the placeholder with your key. Do not commit or share `.env`, and never put the key in frontend JavaScript. The `.gitignore` excludes `.env`.

### 3. Start the Flask backend

In a terminal opened at the project root, run:

```powershell
.\.venv\Scripts\python.exe js\app.py
```

The backend listens at `http://127.0.0.1:5000`. It reads `GEMINI_API_KEY` from the root `.env` file (or the server's environment) and optionally uses `GEMINI_MODEL` to select a model. If unset, the existing `gemini-3.6-flash` model name is used; confirm that this model is available to your Gemini API project.

### 4. Serve the frontend locally

In a second terminal, also at the project root, start a local web server:

```powershell
python -m http.server 8000
```

Open <http://127.0.0.1:8000> in your browser. You can also use the VS Code Live Server extension. Localhost and `127.0.0.1` frontend origins are allowed by the Flask backend.

### Deployment configuration

The frontend reads its API base URL from the `api-base-url` meta tag in `index.html`. Keep it empty to use the local Flask URL during local development and same-origin `/api` routes when deployed together. If the frontend and backend are hosted on separate origins, set the tag's `content` to the backend's HTTPS base URL (without a trailing slash), and set the backend environment variable `CORS_ALLOWED_ORIGINS` to the exact frontend origin. For example:

```html
<meta name="api-base-url" content="https://api.example.com">
```

```text
CORS_ALLOWED_ORIGINS=https://www.example.com
```

Set `GEMINI_API_KEY` as a secret in the backend hosting environment. Never put it in the HTML, JavaScript, or frontend hosting configuration. The browser API base URL is public and must not contain credentials.

### 5. Try a practice session

Choose **Start practicing**, set up your interview, and submit an answer of at least 20 characters. Gemini feedback appears after the backend responds. Continue through all five questions to see the final report.

## Troubleshooting

- **The backend says the API key is missing:** confirm `.env` is in the project root, the variable is named `GEMINI_API_KEY`, and restart Flask after changing `.env`.
- **The browser cannot reach the backend:** make sure Flask is running at `http://127.0.0.1:5000` and the frontend is served from `localhost` or `127.0.0.1`.
- **Gemini cannot generate questions or evaluate an answer:** confirm `GEMINI_API_KEY` is configured on the backend and that the selected `GEMINI_MODEL` is available to the API project.
- **The frontend and backend are deployed separately:** configure the `api-base-url` meta tag and set `CORS_ALLOWED_ORIGINS` to the frontend's exact origin on the backend.
- **Gemini returns an error:** check the Flask terminal for the safe diagnostic status and confirm that the configured model is available to your Gemini API project.
- **Gemini returns `429 RESOURCE_EXHAUSTED`:** Gemini is refusing the request because the API project has reached a usage limit. This can be a short-term request/token rate limit or a longer quota or billing limit. Wait before retrying; if it continues, check the model's quota and billing for the Google project that owns the key. This does not mean the key should be shown in the browser or replaced automatically.
