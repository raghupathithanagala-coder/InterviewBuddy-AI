InterviewBuddy AI is an AI-powered interview practice application designed for students and job seekers. It helps users prepare for interviews by generating role-specific questions and providing personalized feedback on their answers.

Users can select an interview role, interview style, and difficulty level. The application generates five interview questions using Google Gemini. After each answer, users receive an AI evaluation score out of 100, strengths, weaknesses, missing concepts, grammar suggestions, and an improved example answer. It also supports contextual follow-up questions and a final performance report.

The project uses HTML, CSS, and JavaScript for the frontend, Python and Flask for the backend, and the Google Gemini API for AI-powered question generation and answer evaluation.

Our goal is to make interview preparation more accessible, structured, and effective. Future improvements could include voice-based interviews, resume-based questions, and progress tracking.
